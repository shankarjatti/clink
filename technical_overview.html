03 / Quantization & Math Engine

Lossless Fixed-Point Transformation

Float fc32 to Signed 16-Bit Quantization

Transmits normalized floating-point samples ($[-1.0, 1.0]$ or scaled $[-M, +M]$) into 16-bit signed integers, reducing raw network bandwidth by 50% (from 16 MB/s down to 8 MB/s) with zero loss in dynamic range:

int16_t = clamp( round( float_sample * (32767.0f / Multiplier) ), -32768, 32767 )

Signed 16-Bit to Scaled Float Reconstitution

Converts received 16-bit integer stream back into calibrated volt-scale floating point:

float_sample = ( int16_t / 32767.0f ) * Multiplier
